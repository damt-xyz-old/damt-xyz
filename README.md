# damt.xyz

Practical, local-first desktop and command-line software for Windows, Linux, and macOS.
Fast to open, quiet while you work, and built to stay useful.

**Website:** [damt.xyz](https://damt.xyz) · **Microsoft Store:** [Mevit](https://apps.microsoft.com/search/publisher?name=Mevit&hl=en-US&gl=CZ)
